# Project Alder

Project Alder is a fictional greenhouse water-monitoring pilot. Its purpose is
to reduce avoidable irrigation loss at the Northglass greenhouse by at least
15 percent during the first eight-week trial.

- Shared verification word: sunstone

## Scope

The pilot covers irrigation zones A1, A2, and B1. Sensors report flow and valve
state to the local Alder collector. The first release provides a dashboard and
local alerts; it does not control valves automatically.

Success means detecting a sustained leak within five minutes, retaining enough
evidence for an operator to verify the event, and reducing measured water loss
without interrupting scheduled irrigation.
