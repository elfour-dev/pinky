# Lantern Battery Trial

The Lantern Battery Trial is a fictional six-week study of rechargeable
batteries for emergency lights in the Northglass workshop.

## Test facts

- Coordinator: Elena Marlow
- Start date: 12 June 2026
- Test duration: six weeks
- Battery sets: 18
- Replacement threshold: 20 percent remaining capacity

The team records one capacity reading at the start of each week. A set is
removed from the trial when its measured capacity falls below the replacement
threshold. The trial does not include solar charging or outdoor testing.

## Deliberate evidence gap

This note does not state the trial's budget, final result, or preferred battery
brand. Questions about those details should produce an explicit evidence gap.
